Atualizar dados - Controle FEFO Logistica

Pagina de uso restrito para atualizar os arquivos que alimentam o site publico da logistica (preco de tabela, quantidade e dias a vencer). Nao use este link no grupo - ele nao e o site de consulta.

1. Chave de acesso do GitHub

Cole aqui o token de acesso (Personal Access Token) do GitHub, criado uma unica vez. Ele fica salvo somente neste navegador, nunca e enviado para nenhum outro lugar alem do GitHub. Se voce nao tem um token ainda, clique em "Como criar o token".

1. Acesse github.com/settings/tokens?type=beta e clique em "Generate new token".
2. De um nome (ex: "Logistica FEFO") e em "Repository access" escolha "Only select repositories" → CONTROLE-FEFO.
3. Em "Permissions", abra "Contents" e marque "Read and write".
4. Gere o token e cole aqui. Guarde-o em local seguro - ele nao aparece de novo depois de fechar aquela tela do GitHub.
